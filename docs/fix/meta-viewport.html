How to fix zoom blocked on mobile

WCAG 1.4.4 Resize Text, level AA. Rule meta-viewport in axe-core.

What is wrong

The viewport tag contains user-scalable=no, or a maximum-scale below 2. On many phones and tablets this stops visitors from pinching to zoom, so text that is too small for them stays too small.

Who it blocks

Low-vision visitors on mobile, and anyone trying to read small print such as delivery terms or a size chart.

How to fix it

<!-- before -->
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">

<!-- after -->
<meta name="viewport" content="width=device-width, initial-scale=1">

This tag is often in the theme layout file, so one change fixes every page.

Common mistakes

  • Blocking zoom to stop iOS from zooming into form fields on focus. The usual fix for that is a font size of at least 16 px on inputs, not blocking zoom.
  • Removing user-scalable=no but keeping maximum-scale=1.

How the scan proposes a fix

The scan removes only the user-scalable and maximum-scale parts of the content attribute and keeps the rest, then runs the same rule on a page built with the new tag.
