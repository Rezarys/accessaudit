How to fix a missing page title

WCAG 2.4.2 Page Titled, level A. Rule document-title in axe-core.

What is wrong

The page has no <title> element, or it is empty. The title is the first thing a screen reader announces when a page opens, and the name shown in browser tabs, bookmarks and history.

Who it blocks

Screen reader users, people with cognitive disabilities who use the title to know where they are, and anyone with many tabs open.

How to fix it

<head>
  <title>Red steel trowel | Fern and Field</title>
  ...
</head>

Put the specific part first and the shop name last, so the difference between pages is heard first: "Cart | Fern and Field", "Checkout, step 2 of 3: delivery | Fern and Field".

Common mistakes

  • The same title on every page, usually the shop name alone.
  • Single-page checkouts that never update the title between steps.
  • Error pages titled like the page that failed.

How the scan proposes a fix

The scan proposes a <title> built from the site name declared in the page, or the main heading, or the host name, and runs the same rule on a page built with it. Adjust the text so each page has its own title.
